Markdown példa

A Markdown egy könnyen olvasható jelölőnyelv. Így néz ki a forráskódja, és a belőle generált eredmény:

Nyers Markdown kód
# Főcím
Ez egy **félkövér** és egy *dőlt* szöveg.

- Első pont
- Második pont

[Kattints ide a Youtube-hoz](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
Böngészőben megjelenve

Főcím

Ez egy félkövér és egy dőlt szöveg.

  • Első pont
  • Második pont
Kattints ide a Youtube-hoz

LaTeX (TeX) képletek weben

A GitHub Markdownban a képleteket $$ jelek közé tesszük. Ezen a weboldalon a MathJax könyvtár segítségével rajzoljuk ki őket.

A Másodfokú egyenlet megoldóképlete

Nyers TeX kód:

$$x_{1,2}=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$

Ugyanez a weboldalon renderelve:

$$x_{1,2}=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$

A másodfokú egyenlet megoldóképletének levezetése

Induljunk ki az általános alakból, ahol $a \neq 0$:

$$ax^2 + bx + c = 0$$

Vonjunk ki mindkét oldalból $c$-t:

$$ax^2 + bx = -c$$

Osszuk el az egyenlet mindkét oldalát $a$-val:

$$x^2 + \frac{b}{a}x = -\frac{c}{a}$$

Alakítsuk teljes négyzetté a bal oldalt. Ehhez adjuk hozzá mindkét oldalhoz az $x$ együtthatója felének négyzetét, azaz a $\left(\frac{b}{2a}\right)^2$ kifejezést:

$$x^2 + \frac{b}{a}x + \left(\frac{b}{2a}\right)^2 = \left(\frac{b}{2a}\right)^2 - \frac{c}{a}$$

A bal oldal most már felírható egy kéttagú összeg négyzeteként:

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2}{4a^2} - \frac{c}{a}$$

Hozzuk közös nevezőre a jobb oldalt:

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$$

Vonjunk gyököt mindkét oldalból (figyelembe véve a pozitív és negatív gyököt is):

$$x + \frac{b}{2a} = \pm\frac{\sqrt{b^2 - 4ac}}{2a}$$

Végül vonjunk ki $\frac{b}{2a}$-t mindkét oldalból, hogy megkapjuk a végeredményt:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
